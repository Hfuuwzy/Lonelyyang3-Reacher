# Research Material

Keep materials used for study and comparison here, separate from runtime asset sources:

- `images/`: visual references and screenshots.
- `documents/`: PDFs, text documents, and other written references.
- `other/`: reference formats that fit neither category.

These files are not served by the website. Put any image the website must load under `../../public/` and record its origin in `../../ASSET-SOURCES.md`.
