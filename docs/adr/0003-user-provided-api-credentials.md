# ADR 0003: 外部 API 凭证由用户提供

Status: accepted

## 决策

首发版本采用按用户自带凭证（BYOK）：用户为自己使用的外部 API 提供凭证，并承担 API 提供方收取的个人使用费用；平台不为所有用户承担共享付费密钥的费用。各提供方的价格和计费规则可能不同，用户启用所选提供方的 API 前应查看其当前价格和计费规则。凭证配置放在独立的 API 设置页面。页面必须说明所选提供方和协议、将发送给该提供方的请求数据，以及费用由用户承担。无需用户密钥的公开 API 不要求填写凭证。

真实测试凭证如有需要，由用户通过安全的本地渠道提供，绝不粘贴到文档或聊天中，也不提交到版本库。

## 原因

平台承担所有用户的 API 费用并不可负担。按用户提供凭证并承担个人调用费用，明确了首发阶段的平台与用户责任。

## 后果

凭证持久化与存储、后端方案、多用户隔离，以及 DSH 的具体集成方式均留待后续决定；本 ADR 不预设存储位置，也不决定 DSH 的用户凭证隔离实现。
